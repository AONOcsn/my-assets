# 净值 iPhone 改版

依据：用户已确认的《净值 iPhone 资产盘点改版》计划，2026-10-24。

## 约束与决定
- 首次交付在用户指定的本地文件夹修改，保留当前 Git 工作目录。2026-10-24 用户体验满意，明确授权部署 GitHub Pages；账本数据仍保存在各自设备。
- 沿用 React / Vite / IndexedDB，不引入界面或图表运行时依赖。
- 流水计算保持旧版口径；盘点用差额调整记录实现，历史估值快照不反向重算。
- 金额归零与空输入分开；同余额盘点也更新核对时间。一次保存只生成一份快照。
- 趋势不是收益率；缺汇率显示缺口。按设备本地日期分组，保存时记录日期。
- 删除限制依据实际流水与盘点核对历史，不将普通估值快照误认为账户盘点。
